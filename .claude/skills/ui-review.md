# UI Review Skill

## Purpose

Review the Airbnb-style frontend against the provided reference and identify visual or behavioral differences.

## Review Checklist

### Visual

- Page structure matches the reference.
- Header positioning is correct.
- Typography and font sizes are consistent.
- Spacing and alignment are consistent.
- Images use the correct aspect ratios.
- Buttons and icons match the reference.
- Borders, radius, and shadows are consistent.

### Interaction

- Navigation works correctly.
- Photo Tour opens correctly.
- Lightbox opens and closes correctly.
- Previous/next image controls work.
- Keyboard interactions work where applicable.
- Overlays and transitions behave correctly.

### Code

- Components remain reusable.
- No unnecessary duplication was introduced.
- Existing functionality is preserved.
- No unnecessary dependencies were added.

## Workflow

1. Inspect the relevant implementation.
2. Compare the implementation with the reference.
3. Identify the highest-impact differences.
4. Fix only the relevant files.
5. Run the application.
6. Verify the result.
7. Report remaining differences and limitations.
